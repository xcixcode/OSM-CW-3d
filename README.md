# OSM-CW-3d

**오픈스트리트맵 실데이터를 활용하여 창원시 성산구의 지형지물을 로우폴리 스타일의 3D 웹 환경으로 구현한 인터랙티브 도시 시각화 애플리케이션**

---

## 개요

본 프로젝트 **OSM-CW-3d**는 **OpenStreetMap 실데이터와 Three.js**를 활용해 **창원시 성산구 지역의 3D 공간 정보를 시각화**할 수 있도록 제작된 **웹 기반 3D 도시 뷰어 프로젝트**입니다.  
사용자가 **로우폴리 스타일의 3D 그래픽 인터페이스**를 통해 **창원 성산구의 건물, 도로, 지형지물**을 직관적으로 탐색할 수 있는 이점을 얻을 수 있습니다.  
별도의 서버 환경이나 복잡한 빌드 과정 없이 **웹 브라우저**에서 클라이언트 사이드(Client-side)로 작동하여 단순하고 빠르게 실행 가능합니다.  

---

## 기술 스택

* **HTML5** - 페이지 구조 및 콘텐츠 구성
* **CSS3** - 스타일링, 레이아웃, 반응형 디자인
* **JavaScript (Vanilla / ES6+)** - 핵심 로직 및 3D씬 제어, 데이터 파싱
* **Three.js** - 3D 그래픽 렌더링, 카메라 조작 및 로우폴리 지형 구현
* **OpenStreetMap (OSM) API / GeoJSON** - 창원시 성산구 공간 데이터 및 지형 정보 제공

---

## 주요 기능

* **오픈스트리트맵 기반 실데이터 연동**: 창원시 성산구의 실제 지형, 도로, 건물 데이터를 기반으로 한 3D 공간 구성
* **로우폴리(Low-Poly) 3D 그래픽 렌더링**: 가벼우면서도 감각적인 폴리곤 아트 스타일을 적용한 도시 경관 시각화
* **인터랙티브 카메라 컨트롤**: 마우스 조작을 통해 3D 공간 속 도시를 자유롭게 회전, 확대/축소 및 이동하며 탐색
* **반응형 웹 UI 지원**: 데스크톱 및 모바일 환경에서 유연하게 대응하는 인터페이스 레이아웃

## 설치 및 실행

### GitHub Pages

https://xcixcode.github.io/OSM-CW-3d/

### 로컬에서 실행

1. 저장소를 클론하거나 파일을 다운로드합니다.
2. `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 엽니다.
3. 별도의 **서버 설정이나 패키지 설치 없이** 바로 실행됩니다.
   * *인터넷 연결 필요 (Three.js 라이브러리 및 외부 지도 데이터 CDN 사용)*
